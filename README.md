# 호스피스간호실무 진단·형성평가 앱

2026-2 호스피스간호실무(간호학과 4학년) 진단평가 1회와 1~14주차 형성평가를 위한 웹 앱입니다.

- 학생은 휴대폰이나 PC에서 문제를 풀고 **결과 제출**을 누릅니다.
- 결과는 교수님의 구글 스프레드시트에 쌓입니다.
- 교수님은 `admin.html`에서 전체 결과를 확인합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 학생용 페이지 (진단평가 20문항, 1주차 3문항, 2~14주차 각 5문항) |
| `admin.html` | 교수용 결과 확인 (전체 현황, 평가별 결과, 문항 분석, 학생별 성적표, CSV 내려받기) |
| `questions.js` | 문항은행. 문항을 고치려면 이 파일만 수정합니다 |
| `config.js` | 서버 주소(API_URL)와 과목 표시 이름 |
| `apps-script/Code.gs` | 결과를 저장하는 구글 Apps Script 서버 코드 |

---

## 1단계. 결과 저장용 구글 시트와 서버 만들기 (약 10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. 이름 예: `호스피스간호실무_평가결과`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
4. 맨 위의 비밀번호를 교수님만 아는 비밀번호로 바꿉니다.
   `const ADMIN_PASSWORD = "여기에-교수님-비밀번호";`
5. 저장한 뒤, 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
   - 권한 요청 창이 뜨면 본인 계정으로 허용합니다.
   - "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누릅니다.
   - 실행이 끝나면 시트에 `responses` 탭이 생깁니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누릅니다.
7. 나타난 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 나중에 Code.gs를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 순서로 다시 배포해야 반영됩니다. 이렇게 하면 URL은 바뀌지 않습니다.

## 2단계. 서버 주소 넣기

`config.js`를 열어 따옴표 안에 복사한 주소를 붙여 넣습니다.

```js
const API_URL = "https://script.google.com/macros/s/여기에-복사한-주소/exec";
const COURSE_LABEL = "2026-2 호스피스간호실무 · 간호학과 4학년";
```

## 3단계. 깃허브에 올리고 웹사이트로 공개하기 (약 10분)

1. [github.com](https://github.com)에 로그인합니다. 계정이 없으면 가입합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
   - 이름 예: `hospice-eval`
   - **Public**을 선택합니다. 무료 계정에서 GitHub Pages를 쓰려면 공개 저장소여야 합니다.
   - **Create repository**를 누릅니다.
3. **uploading an existing file**을 누르고, 이 폴더의 파일을 모두 끌어다 놓습니다.
   - 대상: `index.html`, `admin.html`, `questions.js`, `config.js`, `style.css`, `README.md`, `apps-script` 폴더
   - **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   - 학생용: `https://아이디.github.io/hospice-eval/`
   - 교수용: `https://아이디.github.io/hospice-eval/admin.html`

## 4단계. 사용하기

- **학생:** 학생용 주소(또는 QR 코드)를 LMS나 첫 수업 슬라이드에 올립니다. 학생은 학번과 이름을 입력하고 평가를 풀고 **결과 제출**을 누르면 끝입니다. 여러 번 풀 수 있고, 교수용 화면에는 학생별 최근 제출이 표시되며 응시 횟수도 함께 보입니다.
- **교수:** `admin.html`에서 1단계에서 정한 비밀번호를 입력합니다.
  - **전체 현황:** 평가별 응시 인원과 평균
  - **평가별 결과:** 학생별 점수, 응시 횟수, 오답 문항 (정렬·검색 가능)
  - **문항 분석:** 문항별 정답률과 보기 선택 분포. 50% 미만은 붉게 표시되므로, 다음 강의 시작 때 다시 짚을 문항을 고르는 데 씁니다.
  - **학생별 성적표:** 학생 × 15개 평가 표와 참여 횟수 (참여도 평가에 활용)
  - **CSV 내려받기:** 엑셀에서 바로 열 수 있습니다.
- 원본 자료는 구글 시트 `responses` 탭에 그대로 남습니다.

## 문항 고치기

`questions.js`에서 해당 문항을 찾아 고친 뒤 깃허브에 다시 올립니다. 각 문항의 구성은 다음과 같습니다.

- `q`: 문제
- `o`: 보기 4개
- `a`: 정답 번호. **0부터 셉니다.** 1번 보기가 정답이면 0입니다.
- `e`: 해설

> 학기 중에 문항 순서나 정답을 바꾸면 이미 제출된 결과의 재채점에 영향을 줄 수 있습니다. 가능하면 학기 시작 전에 확정해 주세요.

## 알아 두실 점

- **학생 본인 확인은 하지 않습니다.** 학번과 이름은 학생이 직접 입력합니다. 성적에 크게 반영한다면 LMS 명단과 대조해 주세요.
- **교수용 비밀번호는 서버(Apps Script)에만 저장됩니다.** 깃허브의 공개 파일에는 들어가지 않습니다. 비밀번호를 바꾸려면 Code.gs의 값을 바꾸고 `setup`을 다시 실행합니다.
- **학생 화면에는 정답과 해설이 표시됩니다.** 형성평가(학습용) 목적에 맞춘 설계입니다. 문항 파일이 공개되어 있으므로 성적용 시험으로는 쓰지 마세요.
- **Apps Script 무료 사용량 안에서** 한 반 규모의 사용은 충분합니다.
